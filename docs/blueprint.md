# **App Name**: DevOps Virtuoso

## Core Features:

- Theme Toggle: Dual theme system: Modern professional theme and futuristic terminal theme with smooth transitions.
- Interactive Terminal: Interactive terminal component that responds to a pre-defined set of commands.
- Pipeline Visualization: CI/CD pipeline visualization in hero section to illustrate deployment workflows.
- Skill Showcase: Dynamic skill matrix with hover effects to showcase technology expertise.
- Technical Blog: Blog section to showcase research and technical articles with a simple admin interface for content creation.
- Interactive Contact Form: Contact form with interactive validation and subtle success animations.
- Personalized Greeting: Generate a personalized greeting for visitors using an LLM tool that conditionally adjusts its language depending on the viewer's likely technical expertise. This tool selects its outputs from a pre-vetted, well-considered set of options.

## Style Guidelines:

- Primary color: A saturated purple (#9400D3) to convey creativity and technical skill, especially in the modern theme.
- Background color: Light theme: a very light purple (#F0E6FF). Dark theme: a nearly black color, to provide stark contrast for the Matrix greens and neon accents, at #111111.
- Accent color: An analogous blue (#007BFF) to highlight interactive elements and calls to action in the modern theme.
- Modern theme: 'Poppins' (sans-serif) for headlines and body text, conveying a contemporary feel. Terminal Theme: 'Source Code Pro' (monospace) for the terminal and code snippets.
- Use DevOps tool icons (Docker, Kubernetes, Jenkins, AWS, etc.) for skill representation.
- Modern: Glassmorphism effects on cards with minimalist design. Terminal: Command-line interface aesthetic with clear sections.
- Subtle animations on theme toggle and hover effects for enhanced interactivity.
